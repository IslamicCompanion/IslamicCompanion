## ✨ About IslamicCompanion

IslamicCompanion is an open-source project dedicated to making Islamic resources and digital tools accessible through a modern, reliable, and user-friendly experience.

Our vision is to build a useful digital companion for Muslims around the world.

## 🎯 Vision

- Make Islamic knowledge accessible.
- Build modern and accessible experiences.
- Encourage learning and daily worship.
- Support open-source development.
- Create technology that benefits the Ummah.
